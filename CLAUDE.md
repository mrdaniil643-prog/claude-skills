# claude-skills

Это репозиторий со скиллами Claude Code, а не приложение.

- Каждый скилл лежит в `skills/<имя>/` и обязательно содержит `SKILL.md` с frontmatter `name` и `description`. `name` совпадает с именем папки.
- При добавлении или удалении скилла обнови таблицу в `README.md`.
- Не меняй содержимое сторонних скиллов без необходимости; их лицензии лежат рядом.
- Версию в `.claude-plugin/plugin.json` поднимай при каждом изменении скиллов, чтобы плагин обновлялся.

# Логотипы, превью, афиши

Работа делается кодом (SVG — логотипы, HTML/CSS/SVG — превью и афиши),
рендерится в точные размеры, **измеряется** линтером, **смотрится глазами** на
листах проверки и **оценивается по рубрике**, пока не дотянет до уровня.

## Процесс

### 1. Бриф
Одним сообщением спроси только недостающее, с вариантами по умолчанию: точный
текст, где будет жить, аудитория, 3 слова характера и 1–2 «точно не», цвета и
шрифты бренда, материалы (фото, лого), референсы, дедлайн. Торопятся — заполни
сам и перечисли допущения. Сформулируй задачу одной фразой (art-direction §1).

### 2. Арт-дирекция
- Референсы есть → `palette.py from-image`, опиши принципы (art-direction §7).
- Выбери 3 разные формулы идей (§2) и для каждой зафиксируй ограничения (§3):
  доминанта, сетка, 2 шрифта, палитра 60/30/10, один приём или ни одного,
  2–3 запрета.
- Логотип/стиль без референсов: сначала покажи 3 направления словами и
  дождись выбора; превью и сторис рисуй сразу.

### 3. Материалы
Нестандартный стиль шрифта (готика, кровь, металл, Y2K...) — сначала `fonts-guide.md`
и образцы с настоящим текстом (`typelib.py specimen`), потом выбор. Эффектный заголовок
(металл, хром, кровь, лёд, неон, лава...) делай в 3D, а не CSS-тенями:
```bash
node $S/text3d.cjs --text "КРОВЬ" --font fonts/DelaGothicOne-400.ttf --preset blood --out title.png
node $S/text3d.cjs --lines "НОЧНОЙ|КЛУБ" --font fonts/Unbounded-900.ttf --preset chrome --bg transparent --size 1600x1000 --out title.png
```
Нужна форма под композицию или свой характер букв — сначала `letterforms.py`
(`references/lettering.md`), потом `text3d.cjs --svg word.svg`.
Прозрачный PNG ставь в HTML-макет обычным `<img>`; угол — `--yaw/--tilt`, толщина —
`--depth`, скругление — `--bevel`, цвет candy/neon/gold/slime — `--color`. Посмотри
результат (Read) и подкрути: больше `--tilt` даёт больше бликов на гранях, `--bevel 0.1+`
надувает буквы. Галерея пресетов: `references/specimens/text3d.jpg` (по порядку: chrome,
gold, steel / rust, blood, slime / ice, glass, y2k / candy, neon, lava / stone).
```bash
S=~/.claude/skills/graphic-design/scripts
python3 $S/fonts.py "Unbounded:700,900" "Manrope:500,800" --out fonts   # шрифты локально
python3 $S/palette.py from-hex "#D9541E" --scheme complement            # палитра + контрасты
python3 $S/assets.py icon-search coffee                                 # иконки (Iconify)
python3 $S/assets.py icon lucide:coffee --color "#13213C" --out icons
python3 $S/assets.py photo "coffee beans macro" --out photos            # фото CC (Openverse) + credits.txt
python3 $S/assets.py cutout face.jpg face-cut.png --person              # вырезать фон (rembg)
```
Фото пользователя важнее стока. Если доступен генератор изображений (Figma
`generate_image`, Adobe Firefly), генерируй им фон/иллюстрацию, а текст и логотип
накладывай кодом. Без фото — типографика, геометрия и приёмы из `recipes.html`.

### 4. Три концепции
Сделай все три, отрендери и собери на один лист:
```bash
node $S/render.cjs a.html a.png --size 1280x720     # то же для b, c
node $S/qa.cjs compare a.png b.png c.png concepts.png --labels "A. Метафора,B. Типографика,C. Контраст"
```
Покажи лист: у каждой концепции — название, мысль одной фразой, рекомендация
с причиной. Дальше работай с выбранной.

### 5. Доводка и проверка — цикл до уровня
Повторяй, пока все пункты не выполнены (обычно 2–3 круга):
1. **Линтер** — 0 FAIL (WARN разобрать и либо исправить, либо объяснить себе):
   ```bash
   node $S/check.cjs thumb.html --kind thumb
   node $S/check.cjs cover.html --kind cover
   node $S/check.cjs poster.html --kind poster --mm 420x594 --bleed 3
   ```
   Меряет контраст текста по реальным пикселям фона, размеры, зоны таймкода и
   интерфейса, безопасное поле, незагрузившиеся шрифты, число шрифтов и цветов.
   Намеренный выход текста за край помечай атрибутом `data-crop`.
2. **Лист восприятия** — открой через Read и пройди чек-лист справочника:
   ```bash
   node $S/qa.cjs thumb thumb.jpg qa.png --title "Название" --channel "Канал"
   node $S/qa.cjs logo mark.svg qa.png      # и logo.svg
   node $S/qa.cjs cover cover.png qa.png
   node $S/qa.cjs poster poster.png qa.png
   ```
3. **Рубрика** (art-direction §6): 8 критериев, все ≥ 4. Пиши конкретно, что
   мешает 5-ке, правь самое слабое место первым.
4. **Факты**: сверь текст с брифом; день недели вычисляй, не пиши по памяти:
   `python3 -c "import datetime;print(datetime.date(2026,11,15).strftime('%A'))"`.
   `WARN` от `render.cjs` (текст за краем или не влез) — всегда ошибка.

### 6. Сдача
- **Логотип:** финальные SVG в кривых (`text2path.py`), затем
  ```bash
  node $S/brandkit.cjs --logo logo.svg --mark mark.svg --logo-dark logo-on-dark.svg \
    --colors "#13213C:Ночь,#D9541E:Ржавчина,#F3ECE0:Крем" --fonts "Unbounded,Manrope" --name "Север" --out kit
  ```
  Пакет: SVG (цвет, чёрный, белый, для тёмного фона), PNG 512–2048, favicon.ico,
  apple-touch-icon, icon-512, og-image 1200×630, лист фирменного стиля PNG+PDF.
- **Превью/обложки:** JPG/PNG точного размера + лист `qa.cjs`; предложи 2-й
  вариант для A/B-теста.
- **Афиша:** `poster-print.pdf` с вылетами (`render.cjs --mm ... --bleed 3`),
  превью PNG, версии 1080×1920 и 1080×1350, пересобранные под экран. Предупреди
  про RGB→CMYK (poster.md).
- В ответе: идея одной фразой, шрифты, цвета HEX, оценки рубрики, что
  предлагаешь дальше.

## Инструменты — справка

| Скрипт | Что делает |
|---|---|
| `render.cjs` | HTML/SVG → PNG/JPG/PDF/ICO точного размера; `--mm --bleed --dpi` для печати, `--sizes` для иконок, `--guides` направляющие; предупреждает о тексте за краем |
| `check.cjs` | линтер макета: контраст, размеры, зоны, шрифты, цвета; код выхода 1 при FAIL |
| `qa.cjs` | листы восприятия: logo, thumb, cover, poster, compare |
| `text2path.py` | надпись → SVG-кривые с кернингом, лигатурами, OpenType-фичами, осями (`uv run --with uharfbuzz --with fonttools python ...`) |
| `fonts.py` | Google Fonts → локальные TTF + fonts.css (дописывает, не перезаписывает) |
| `letterforms.py` | надпись → контуры: операции над буквами, замена символов SVG-рисунком, деформации всей надписи; SVG в кривых (для логотипа, макета или `text3d.cjs --svg`) |
| `text3d.cjs` | 3D-текст: выдавленные буквы с фаской, PBR-материалы, отражения студии/неба, свечение, капли и сосульки геометрией; PNG, в т. ч. прозрачный для вставки в макет |
| `typelib.py` | библиотека выразительных шрифтов: стили, поиск, загрузка, образцы с твоим текстом, проверка букв, добавление своих шрифтов |
| `palette.py` | палитра от цвета (OKLCH, шкала, роли, матрица контраста), из картинки, контраст пары |
| `assets.py` | иконки Iconify (API или npm-пакет), CC-фото Openverse с авторством, вырезка фона rembg |
| `brandkit.cjs` | пакет логотипа и лист фирменного стиля |

## Права

Чужие логотипы, персонажей и фото без лицензии не используй; для CC BY фото
указывай авторство из `credits.txt`. Стиль известного дизайнера можно взять как
направление, но не копировать конкретную работу. Шрифты Google Fonts — OFL,
можно в коммерческих логотипах.

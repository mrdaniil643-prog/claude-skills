# Логотипы, превью, афиши

Работа делается кодом (SVG для логотипов, HTML/CSS/SVG для превью и афиш),
рендерится в точные размеры и **проверяется глазами на скриншотах** до сдачи.
Инструменты: `~/.claude/skills/graphic-design/scripts/`. Правила по типам —
в `references/` (прочитай нужный файл перед работой):

| Задача | Справочник | Шаблон |
|---|---|---|
| Логотип, знак, фирменный стиль | `references/logo.md` | — (SVG с нуля) |
| Превью YouTube/VK, обложка Reels/Shorts | `references/thumbnail.md` | `templates/thumbnail.html` |
| Афиша, постер, флаер | `references/poster.md` | `templates/poster.html` |
| Шрифты с кириллицей, палитры, эффекты | `references/type-and-color.md` | — |

## Процесс

### 1. Бриф (коротко)
Собери только недостающее, одним сообщением, с вариантами по умолчанию:
текст (точно, с регистром), для чего и где будет жить, аудитория, 3 слова
характера и 1–2 «точно не», цвета/шрифты бренда, материалы (фото, лого),
референсы. Если пользователь торопится — заполни сам и явно перечисли допущения.

### 2. Три концепции, а не три цвета
Сделай 3 направления, которые отличаются **идеей** (метафора, композиция,
типографический приём). Для каждого: название, одна фраза о мысли, рендер.
Покажи их одним листом (`render.cjs` каждого, затем склей контакт-лист
через `qa.cjs` или ffmpeg `hstack`) и порекомендуй один с причиной.

Для каждой концепции опиши себе до кода: доминирующий элемент, сетку,
2 шрифта, палитру 60/30/10. Избегай шаблонного «ИИ-дизайна»: центрированный
текст на градиенте, фиолетово-синие градиенты по умолчанию, эмодзи как иконки,
тени и скругления на всём, стоковые 3D-фигуры, Inter/Arial как акцидентный шрифт.

### 3. Доработка выбранного
Сетка, оптические поправки, кернинг, пары шрифтов, реальный текст. Шрифты —
локально (`fonts.py`), логотип — в кривых (`text2path.py`).

### 4. Проверка — обязательно
```bash
S=~/.claude/skills/graphic-design/scripts
node $S/qa.cjs logo   logo.svg   qa.png
node $S/qa.cjs thumb  thumb.jpg  qa.png --title "Название видео" --channel "Канал"
node $S/qa.cjs cover  cover.png  qa.png
node $S/qa.cjs poster poster.png qa.png
```
Открой лист через Read и пройди чек-лист раздела «Проверка» из справочника.
Исправляй и перепроверяй, пока всё не пройдёт; не сдавай без этого шага.
Сверь все факты в тексте (даты, цены, имена, адреса) с брифом. День недели
не пиши по памяти, вычисли: `python3 -c "import datetime;print(datetime.date(2026,11,15).strftime('%A'))"`.
Строки `WARN` от `render.cjs` (текст за краем холста или не влез в блок) —
всегда ошибка: исправь до сдачи.

### 5. Сдача
Отдай пакет файлов из справочника (раздел «Что отдаём»), лист проверки
и 2–3 строки о решении: идея, шрифты, цвета (HEX). Предложи 1–2 следующих
шага (вариант для тёмного фона, серия превью, версия афиши для сторис).

## Инструменты

```bash
S=~/.claude/skills/graphic-design/scripts

# Шрифты Google Fonts локально (TTF + fonts.css), кириллица включена
python3 $S/fonts.py "Unbounded:700,900" "Manrope:400,700" --out fonts

# Надпись логотипа в кривые с кернингом, лигатурами и вариативными осями
uv run --with uharfbuzz --with fonttools python $S/text2path.py fonts/Unbounded-900.ttf "СЕВЕР" \
  --size 200 --tracking 0.04 > wordmark.svg

# Рендер
node $S/render.cjs thumb.html thumb.jpg --size 1280x720 --quality 90
node $S/render.cjs cover.html cover.png --size 1080x1920
node $S/render.cjs poster.html poster.pdf --mm 420x594 --bleed 3          # в типографию
node $S/render.cjs poster.html poster.png --mm 420x594 --bleed 3 --dpi 150 # превью
node $S/render.cjs poster.html guides.png --mm 420x594 --bleed 3 --guides  # с направляющими
node $S/render.cjs logo.svg png/logo.png --sizes 512,1024 --transparent
node $S/render.cjs mark.svg favicon.ico --sizes 16,32,48
```

Шаблоны копируй в рабочую папку и меняй; рядом клади `fonts/` из `fonts.py`.

## Картинки и фото

- Фото пользователя: используй как есть, обрабатывай CSS/SVG-фильтрами
  (кадрирование, `object-position`, тонирование, дуотон через `feColorMatrix`).
  Вырезать фон умеют `rembg` (`uvx rembg i in.jpg out.png`) или Photoshop
  (скилл `adobe-desktop`).
- Если доступен генератор изображений (Figma `generate_image`, Adobe Firefly
  через коннектор Adobe) — генерируй фон/иллюстрацию, текст и логотип всё
  равно накладывай кодом поверх, а не генерируй картинкой.
- Без генератора стройся на типографике, геометрии, градиентах, зерне и
  SVG-иллюстрации — это и есть сильные стили (см. справочники).
- Чужие логотипы, персонажей и фото без прав не используй; узнаваемый стиль
  известного дизайнера можно описать как направление, но не копировать работу.

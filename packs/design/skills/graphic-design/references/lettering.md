# Свои буквы: геометрия надписи и дизайн букв и цифр

`scripts/letterforms.py` берёт любой шрифт (кириллица, кернинг, лигатуры), превращает
буквы в контуры и даёт их перерисовать и согнуть. Результат — SVG в кривых:
логотип, заголовок для макета или исходник для 3D (`text3d.cjs --svg`).
Галереи: `references/specimens/letterforms.jpg` (все операции),
`references/specimens/letterforms-3d.jpg` (они же в 3D).

```bash
S=~/.claude/skills/graphic-design/scripts
LF="uv run --with shapely --with fonttools --with uharfbuzz --with svgelements python $S/letterforms.py"
$LF --font fonts/RussoOne-400.ttf --lines "ХЭВИ|МЕТАЛ" --op spikes=0.12,100 --warp arch=0.35 --out word.svg
$LF --font fonts/Unbounded-900.ttf --text "2025" --char "0=replace:star.svg" --char "5=rotate=-12;scale=1.2" --out year.svg
node $S/text3d.cjs --svg word.svg --preset steel --out word.png        # в 3D
node $S/render.cjs word.svg word.png --size 1600x900                  # или плоско
```

## Когда что делать

| Задача композиции | Чем | Пример |
|---|---|---|
| Надпись по кругу: эмблема, печать, бейдж, значок | `--warp circle=360` (текст с пробелом и • в конце) | «• КОФЕЙНЯ СЕВЕР • С 2019 » |
| Надпись над/под картинкой, «радуга» | `--warp arc=30…60` (минус — улыбка) | вывеска, спортивная форма |
| Заголовок должен «вставать» в верх кадра | `--warp arch=0.3…0.6` | афиша концерта, колледж |
| Объём/надутость без 3D | `--warp bulge=0.3…0.5`, `fisheye=0.3` | Y2K, детское |
| Динамика, нарастание, скорость | `--warp rise=0.6…1.2`, `skew=10…15` | спорт, распродажа |
| Уход в глубину, «звёздные войны» | `--warp perspective=0.4…0.6` | постер, интро |
| Жидкость, музыка, вода | `--warp wave=0.06…0.15,1` или `flag` | диджей, аквапарк |
| Рукотворность, «живой» шрифт | `--warp jitter=6…12,0.03…0.06` | детское, крафт, хоррор |

Деформация — одна на надпись (иногда arch/arc + jitter). Две сильные подряд
убивают читаемость.

## Дизайн букв: операции по стилям

| Стиль | Рецепт (`--op`) | Шрифты |
|---|---|---|
| Хоррор, кровь | `rough=0.008…0.012`, затем `drip=0.3…0.45,2` | Dela Gothic One, Rubik Mono One, Russo One |
| Блэк-метал / металл | `spikes=0.1…0.16,100…120` (шипы на острых углах) | Russo One, Stalinist One, Ruslan Display |
| Колючий, панк | `thorns=0.04…0.06,0.14…0.2` | любой жирный гротеск |
| Готика из гротеска | `spikes=0.08,95` + `--warp arch=0.25` | Ruslan Display, Shafarik |
| Армия, индастриал | `stencil=0.04…0.06,1` (скругление — до прорезей) | Unbounded 900, Russo One |
| Глитч, кибер | `slice=5…8,0.02…0.04` | Unbounded, Tektur |
| Мягкий, Y2K, детский | `round=0.03…0.06` + `weight=0.02` + `--warp bulge` | Unbounded, Rubik Bubbles, Comfortaa |
| Контурный, ретро-вывеска | `outline=0.025…0.04` | любой жирный |
| Гравюра, банкнота, премиум | `inline=0.01…0.015,0.025…0.035` | Unbounded 900, Yeseva One |
| Ручная работа | `rough=0.004` + `--warp jitter=6,0.03` | любой |

Порядок операций важен: они применяются слева направо. Скругление после
прорезей заливает прорези; `weight` после `outline` утолщает стенку.

## Дизайн отдельных букв и цифр (`--char`)

- `--char "О=replace:eye.svg"` — заменить букву своим рисунком: иконкой
  (`assets.py icon lucide:eye`), знаком логотипа, нарисованной SVG-фигурой.
  Рисунок подгоняется по высоте прописной. Контурные иконки утолщаются до
  своего stroke-width; для жирного шрифта добавь `;weight=0.03` после замены.
- `--char "5=rotate=-12;scale=1.2"` — выделить одну цифру/букву: повернуть,
  увеличить, сдвинуть (`shift=0,0.1`), отдельно состарить (`rough=…`).
- Любая операция из списка работает и для одного символа:
  `--char "А=spikes=0.15"`, `--char "Ь=drip=0.5,1"`.
- Заменённая буква — одна на слово, и она должна быть понятна: «О» → кольцо,
  глаз, мишень, луна, монета, шина; «А» → треугольник/гора; «I» → молния;
  «0» → звезда, кольцо, мяч; «Х» → скрещённые предметы. Проверь читаемость
  на мелком размере (`qa.cjs`): если слово перестало читаться — откатись.
- Свою фигуру рисуй в SVG `path` (заливка), viewBox любой — масштаб подберётся.

## Проверка

1. Рендер SVG крупно и мелко (`qa.cjs logo word.svg qa.png`): читается ли
   слово в 64 px, не слиплись ли буквы после `weight`/`spikes`.
2. После деформации проверь кернинг: на дуге/круге буквы снаружи расходятся,
   внутри сходятся — подправь `--tracking` (+0.02…0.05 для circle).
3. Для логотипа — это уже кривые; дальше `brandkit.cjs`.

# Молодёжная музыкальная сцена: афиши, логотипы артистов, Telegram

Одна задача — **визуальная система артиста**: имя-логотип, афиши туров и
концертов, оформление Telegram-канала, сторис и стикеры выглядят как одно целое.
Делай систему, а не отдельные картинки: сначала ядро, потом носители.

## 1. Ядро системы (до любой афиши)

1. **Направление** — одно из таблицы ниже (или смесь двух, если они не спорят).
   Есть референсы от пользователя (скриншоты афиш, обложек) — сначала
   `palette.py from-image` по каждому и описание: шрифт (класс), обработка фото,
   декор, композиция. Бери приёмы, не копируй чужие афиши и логотипы.
2. **Имя артиста как логотип**: шрифт из `fonts-guide.md` → `letterforms.py`
   (характер букв, деформация) → вариант в 3D (`text3d.cjs`) для афиш и
   плоский SVG для мелких носителей (аватар, стикеры, подписи).
3. **Палитра**: 1 фон + 1 акцент + 1 светлый (`palette.py`), проверенный контраст.
4. **Обработка фото** — один рецепт `phototreat.py` на всю систему.
5. **Декор** — один тип из `ornaments.py` (сигилы, трайбл, искры, проволока, цепи),
   или рисунок от руки `handdrawn.py` одним инструментом (`handmade.md`), или ни
   одного. Векторный орнамент и ручной рисунок в одной системе не смешивай.
6. **Второй шрифт** для дат, городов, подписей — спокойный гротеск (Manrope,
   Inter, Onest, Golos Text), не декоративный.

Запиши ядро в `brand.json` рядом с проектом (шрифты, цвета HEX, рецепт фото,
декор, сид орнамента) — следующие носители берут всё оттуда.

## 2. Направления

Галереи: `specimens/ornaments.jpg` (ряды: sigil, tribal, wings, crown — колонки
`--seed 1…6`; ниже sparkle, star, cross, heart, barbed, chain), `specimens/photo-fx.jpg`
(по порядку: `flash,crush,grain` · `xerox,grain` · `duotone,halftone` · `dream,chroma,grain` /
`vhs` · `pixel,scanlines` · `bitmap` · `motion,chroma,crush`).

| Направление | Как выглядит | Чем делать |
|---|---|---|
| Тёмный rage / opium | чёрный фон, красный или белый акцент, острые/готические буквы, жёсткая вспышка, зерно, мелкий текст по краям, много пустоты | шрифт: Ruslan Display, Shafarik, Dela Gothic One + `spikes`; фото: `flash,crush,grain=0.18`; декор: `sigil` красным; 3D: `chrome`, `steel`, `blood` |
| Саундклауд-дымка / plugg | мягкий фокус, свечение, пастель или сумерки, тонкие искры, рукописные/антиква | шрифт: Great Vibes, Cormorant, Comforter + `round`; фото: `dream,chroma=3,grain=0.08`; декор: `sparkle`; 3D: `glass`, `y2k` |
| Хайпер-поп / Y2K | хром-пузыри, кислотные градиенты, бабочки и звёзды, стикеры, перламутр | шрифт: Rubik Bubbles, Climate Crisis, Unbounded + `bulge`; 3D: `y2k`, `candy`, `chrome`; декор: `sparkle`, `star`, `heart`; стикеры `tgkit.cjs` |
| Кибер-сигилизм / нео-трайбл | тонкие колючие симметричные линии, серебро на чёрном, готика | `ornaments.py sigil|wings|tribal|crown`; шрифт + `spikes`/`thorns`; 3D: `chrome`, `steel` |
| Ксерокс / DIY-зин | ч/б фотокопия, скотч, маркер, коллаж, кривой набор | фото: `xerox=0.5,grain=0.25` или `bitmap`; шрифт: Rubik Marker Hatch, Rubik Spray Paint, Special Elite + `rough`, `jitter`; цвет: ч/б + 1 кислотный |
| Фонк / дрифт | чёрно-красный, VHS, хром-надписи, черепа, скорость | фото: `vhs`, `motion=40,0`; шрифт: Russo One, Stalinist One + `skew`, `rise`; 3D: `chrome`, `lava` |
| Гранж / металкор | рваные края, ржавчина, колючая проволока, кровь | `rough`, `drip`; 3D: `rust`, `blood`; декор: `barbed`, `chain`, `cross` |
| Ткань / печать на холсте | кремовый лоскут с бахромой на чёрном, фото в рамке от руки, чёрная плашка с жирным гротеском, пропись, тату-флеш грифоны, лилии, черепа | `show-canvas.html` + `textures.py canvas`; см. `show-poster.md` |
| Жидкий металл + мембраны | мятое серебро, красная симметричная сеть ячеек, артист-наклейка с белым краем, выдавленный красный широкий гротеск, хром | `show-chrome.html` + `textures.py metal`, `cells`; см. `show-poster.md` |
| Ручной / живописный (скетчбук, тату-флеш) | фон-эскиз из крестов, звёзд, штриховки; фото как живопись или рисунок; надпись от руки; бумага, всё одним инструментом и одним цветом | `handdrawn.py bg --tool pencil|charcoal|ink`; фото: `paint=8,paper`, `sketch,paper`, `ink=0.5,paper`; шрифт: Caveat, Amatic SC, Ruslan Display + `jitter`/`rough`; пометки от руки `circle`, `underline`, `arrow` — см. `handmade.md` |
| Лоу-фай интернет / пиксель | пиксели, окна ОС, битмапы, глитч | Press Start 2P, Tiny5, Handjet; фото: `pixel=12,scanlines`; `slice` для глитча; 3D: `neon` |

## 3. Афиша концерта

**Один концерт в одном городе** — основной случай: `show-poster.md`,
шаблоны `show-canvas.html` (ткань) и `show-chrome.html` (жидкий металл).
Тур с несколькими датами — только если попросили, тогда `tour-poster.html`:

Данные в одном объекте `TOUR` (имя, подзаголовок, даты-города-площадки, возраст,
QR, строка партнёров) → три формата из одного файла:
```bash
node $S/render.cjs tour-poster.html print.pdf --mm 420x594 --bleed 3 --query format=a2
node $S/render.cjs tour-poster.html post.png  --size 1080x1350 --query format=post
node $S/render.cjs tour-poster.html story.png --size 1080x1920 --query format=story
node $S/check.cjs tour-poster.html --kind cover --query format=story   # сторис: зоны интерфейса, контраст
uv run --with opencv-python-headless python $S/assets.py qrcheck post.png
```
Обязательно на афише: имя (главное пятно), дата(ы) и город(а), площадка,
возрастной ценз (12+/16+/18+), как купить (QR + короткая ссылка), организатор.
Один город — дата и город крупно, второй уровень иерархии; тур — список с
выравниванием по датам (шаблон сам уменьшает список, чтобы он влез).
QR тёмный на светлой плашке, не под зерном/текстурой, ≥ 20 мм в печати;
проверяй `qrcheck` на готовом файле. Сверь даты, дни недели, города, площадки.

Анонс в Telegram — те же элементы, но пост 4:5 (1080×1350 или 1280×1600) и
сторис 9:16 со своими зонами (сверху ~12 % плашка профиля, снизу ~20 % поле
ответа, справа кнопки — `check.cjs --kind cover` это ловит).

## 4. Telegram-канал (`scripts/tgkit.cjs`)

| Носитель | Размер | Как |
|---|---|---|
| Аватар | 640×640 (и 1280), показывается кругом | знак/монограмма/фото; `tgkit.cjs avatar logo.svg out --bg "#hex" --pad 0.16`; смотри `avatar-check.png`: содержимое внутри пунктира 80 %, читается в 40 px |
| Пост-картинка | 1280×1600 (4:5) или 1280×1280 | шаблоны-серия: анонс, релиз, тур-даты, цитата/текст — одна сетка и шрифты |
| Сторис | 1080×1920 | зоны как у Reels, `check.cjs --kind cover` |
| Стикеры | 512×512 PNG, прозрачные | `tgkit.cjs stickers a.png b.svg … out` — белая высечка и тень; загрузка через @Stickers |
| Превью ленты | — | `tgkit.cjs preview out.png --avatar … --posts a.png,b.png --texts "…|…"` — как это выглядит в телефоне, тёмная и светлая тема |

Серия постов: одинаковое место для заголовка, одинаковые поля, один приём
оформления, меняется только контент. Обложку релиза делай квадратом 3000×3000
(площадки) и пересобирай под 4:5 для поста, а не растягивай.

## 5. Правила, которые делают «как у артистов», а не «как шаблон»

- Имя артиста — всегда главный объект; дат и подписей много, но они мелкие и
  собраны в один блок.
- Один сильный приём на носитель (3D-хром, или сигилы, или ксерокс-фото).
- Пустота и мелкий текст по краям — признак жанра; не заполняй поле «чтобы
  было красиво».
- Латиница допустима в стилизованных словах (TOUR, LIVE, VOL.), но города,
  даты и как купить — по-русски.
- Фото артиста — только с разрешения; логотипы площадок и партнёров — их
  официальные файлы, без перерисовки. Не копируй чужие афиши и шрифты-логотипы
  других артистов.
- Перед сдачей: `check.cjs`, `qa.cjs`, `qrcheck`, рубрика из `art-direction.md`.

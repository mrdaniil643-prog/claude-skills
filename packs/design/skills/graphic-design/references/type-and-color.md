# Шрифты и цвет

## Шрифты Google Fonts с кириллицей (скачать: `fonts.py`)

Перед использованием всегда проверяй, что все символы текста есть в шрифте:
рендер покажет запасной шрифт в местах, где глифа нет, а `text2path.py`
завершится ошибкой.

## Правила набора

- 2 гарнитуры максимум (акцидентная + текстовая), контраст между ними по
  характеру, а не по мелочам.
- Шкала размеров по модульной прогрессии (×1.25 / ×1.333 / ×1.618).
- Капс: трекинг +4…+10 %; крупные заголовки строчными: −1…−3 %.
- Интерлиньяж: заголовки 0.9–1.1, текст 1.35–1.5.
- Кавычки «ёлочки», тире — с пробелами, неразрывные пробелы после предлогов
  и между числом и единицей (300 000 ₽, 18+). Буква ё, где она нужна.
- Висячие предлоги и одиночные слова в последней строке убирай переносом.

## Цвет

- Палитра: 1 доминирующий (60 %), 1 вторичный (30 %), 1 акцент (10 %).
- Строй в OKLCH (CSS `oklch()`): одинаковая светлота у оттенков одного уровня,
  ровные шаги светлоты для тёмных/светлых вариантов.
- Контраст текста: ≥ 4.5:1 для мелкого, ≥ 3:1 для крупного (WCAG); на превью
  и афишах стремись к 7:1 у главного текста.
- Тёмный фон — не чистый #000, а с оттенком (#0E0F12, #12100E); светлый —
  не всегда чистый #FFF (#F6F3EE тёплый, #F3F5F7 холодный).
- Готовые сочетания-стартеры:
  - Ночь и неон: #0B0B12 / #F5F5F7 / #C6FF3D
  - Тёплый крафт: #F3ECE0 / #2B2118 / #D9541E
  - Глубокий синий: #0D1B3D / #F2F4FA / #FFB400
  - Чистый швейцарский: #F4F1EA / #111 / #E3241B
  - Мята и графит: #E8F3EE / #1E2A27 / #1FAF7A
  - Пастель для детей: #FFF6E9 / #3A2E5F / #FF7AA2 / #6ED3CF

## Текстуры и эффекты кодом (SVG/CSS)

Готовые проверенные блоки — `templates/recipes.html`. Контурный текст делай
фильтром `#outline` оттуда: `-webkit-text-stroke` у многих шрифтов Google
рисует перекрывающиеся контуры внутри букв.


- Зерно: `<feTurbulence baseFrequency="0.8" numOctaves="2">` + `feColorMatrix`,
  накладывать с `mix-blend-mode: multiply` и прозрачностью 0.08–0.2.
- Риз-смещение: два слоя одного текста разными цветами со сдвигом 1–3 px и
  `mix-blend-mode: multiply`.
- Хром/металл: многоступенчатый `linearGradient` с резкими переходами
  светлого/тёмного + тонкая светлая обводка.
- Мягкие формы: `filter: blur(60–120px)` на цветных кругах для градиентных фонов.
- Обводка выреза человека на превью: `filter: drop-shadow(0 0 0 #fff)` в
  несколько слоёв или SVG `feMorphology operator="dilate"`.
